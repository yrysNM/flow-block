# Project Rules

## General

- Never modify requirements without PM approval.
- Prefer existing architecture over introducing new patterns.
- Do not duplicate existing functionality.
- Check existing code before creating new files.

## Git

- Do not reset or delete user changes.
- Do not force push.
- Keep commits focused.

## Testing

Every feature must include appropriate tests.

## API

Backend APIs must have:
- validation
- error handling
- typed responses
- authentication where required
