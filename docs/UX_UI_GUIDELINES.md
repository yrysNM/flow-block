# UX and UI guidelines

The interface is a calm productivity tool: light surfaces, one blue action color, short labels, and no decorative noise.

- One primary action per view (New task, Log in, Save)
- Empty states explain what is missing and offer the next action
- Status, priority, and quadrant are visible without opening the editor
- The form states that urgency and importance do not change status
- The matrix states that a quadrant move does not change status. The planner states that a time move does not change status or quadrant
- Matrix quadrants stack on a narrow screen and sit in a two-by-two grid from the tablet width up. The planner stacks the timeline and the unscheduled list until a wide screen
- Errors from the API are shown as text, not only a color
- Buttons and links have visible keyboard focus
- The sidebar lists the shipped pages, including Settings. It does not label a Soon section
- Desktop keeps a fixed sidebar. Smaller widths use a Menu button and an overlay drawer
- Do not invent sample tasks. An empty account looks empty

Light, dark, and system themes are applied on the shell from the saved preference. System follows the device. Language is stored as English and is not a translation system. The shell shows an unread count for in-app notifications. There is no email or push.
