# Analytics metrics

The analytics dashboard is not implemented. No chart library is installed.

The dashboard is operational:

- Count of tasks in each status
- Count of tasks whose deadline falls today in the user’s time zone
- Today’s habit check-ins and active goals, as lists loaded for those pages

Later metrics called for by the product vision (focus minutes, sites visited, completion rate, weekly review, focus score) have no analytics queries. Do not invent numbers in the UI.
